# mottophoto（もっとフォト）📸

指定したフォルダ内の写真画像を一括で読み込み、BGMの長さに合わせた美しいトランジションとテキスト演出付きのスライドショーを作成し、そのまま**MP4動画**として保存・書き出せるWebアプリケーションです。

---

## 🌟 主な機能

1. **フォルダ一括読み込み**:
   - 「📁 フォルダを選択」からフォルダを指定するだけで、中の写真（JPG, PNG, WEBP等）を一気に読み込みます。
   - ブラウザへのドラッグ＆ドロップ（フォルダ・複数ファイル）にも対応。
   - 自然なファイル名順（`01.jpg`, `02.jpg` ...）で自動ソート。
2. **スライドショー再生（プレビュー）**:
   - 1920×1080 (Full HD) の高画質キャンバス。
   - 写真が映画のように動く「ケン・バーンズ演出（緩やかなズーム＆パン）」と滑らかなクロスフェード切り替え。
   - スペースキーでの再生/一時停止、シークバーでの早送り/巻き戻し、フルスクリーン対応。
3. **BGM自動同期 & タイミング均等計算**:
   - お好みの音楽ファイル（MP3, WAV, M4A等）を指定可能。
   - **BGMの総再生時間に合わせて写真スライドの切り替え時間を自動計算**。
   - 最初（タイトル）と最後（Fin）を少し長めに確保し、残りの時間を写真枚数でぴったり均等配分します。
4. **1枚目：タイトル・サブタイトル・日付の文字入れ**:
   - メインタイトル、サブタイトル、日付/場所を自由に設定可能。
   - 背景グラデーション（ダーク、バイオレット、サンセット、オーシャン、または1枚目写真のシネマティックぼかし）を選択可能。
5. **最終スライド：Fin画面**:
   - 「Fin」をはじめ、「The End」「ありがとう」など自由に文字を変更可能。
6. **再生前のスライド編集**:
   - **順番の並べ替え**: サムネイルをドラッグ＆ドロップ、または「◀」「▶」ボタンで直感的に入れ替え。
   - **簡単な画像処理**:
     - **明るさ（Brightness）**: スライダーで暗い写真を明るく補正。
     - **大きさ（Zoom）**: 50%〜250%でズーム調整。
     - **トリム（Trim / Pan）**: 編集画面の写真を直接マウスでドラッグして構図を調整。枠いっぱい（Cover）と全体表示（Contain）の切り替え対応。
7. **MP4動画として保存（書き出し）**:
   - 「🎬 MP4で書き出し」ボタンを押すだけで、ブラウザ内で映像とBGM音声を結合し、進捗バー（0%〜100%）表示付きで高画質MP4ファイルとして自動保存します。

## 🚀 起動方法

### 方法1: Google Chromeで直接開く（一番手軽）
1. `index.html` をGoogle Chromeにドラッグ＆ドロップするか、右クリックして「このアプリケーションで開く」→「Google Chrome」で開きます。
   - 直接ファイルを開くだけで、外部サーバーなしにオフラインでも全機能が動作します。

### 方法2: ローカルサーバーで開く
ターミナルで本ディレクトリ（`mottophoto`）にて以下を実行します：
```bash
npm start
```
起動後、ブラウザで `http://localhost:3000` を開きます。

## 💡 お試し方法（クイックスタート）
画面中央の **「🌟 サンプル写真で試す」** ボタンをクリックすると、5枚の美しいサンプル写真が即座に生成されて読み込まれます。フォルダを選択する前に、すぐに再生や編集、MP4書き出しを試すことができます。
